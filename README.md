# NoScroll Shorts - 最強ドパガキ対策 (Chrome Extension)

YouTube Shortsのスクロール、下送りボタン、次の動画を完全消滅させ、無限スワイプによるドパミン中毒を徹底的に遮断する最強のChrome拡張機能です。

---

## 🎯 開発の背景と目的
Shorts動画は、指先ひとつ・ホイール1回転で次の刺激（ドーパミン）が供給される構造になっており、気づかないうちに何十分・何時間も人生の時間を溶かしてしまいます（いわゆる「ドパガキ」状態）。

本拡張機能は、**「次の動画へ進む手段」を物理的・視覚的に徹底排除**し、1本の動画を見たらそこで強制終了、あるいはShortsの毒性そのものを無力化することを目的に作られました。

さらに、**「視聴後に現実復帰するための脱出ボタン（Googleトップ等）」「YouTubeトップ」「Watchビュー（通常動画）」** への移動手段を完備しています。

---

## 🚀 主な機能

### 1. 🛡️ スクロール＆次送りの完全封殺 (ポップアップでON/OFF切替可能)
- **マウスホイール / トラックパッド遮断**: ホイールスクロールによる次動画への遷移を水際でブロック。
- **キーボード次送り遮断**: `↓ (ArrowDown)`、`PageDown`、`End`、`j` / `k` によるリール移動を完全に無効化。
- **スワイプ / ドラッグ遮断**: タッチパッドやスワイプ操作による次動画へのスクロールを無力化。
- **ポップアップでワンタッチ切替**:
  拡張機能アイコンをクリックすると開くポップアップ最上部に、大きな **「🛡️ スクロール禁止: 有効 / 無効」** マスタースイッチを搭載！
  一時的にスクロールしたい時はOFFにすれば、すぐに通常のスクロールが可能になります。

### 2. 🚪 視聴後ポップアップの脱出ナビゲーション
動画を1本見終わった際（ループ防止モード）や警告タイマー発動時に表示されるポップアップに、3つの主要な遷移先をスタイリッシュに配置：
1. **🌐 Googleトップ (現実復帰・変更可)**:
   YouTubeから完全に脱出して作業や検索に戻るためのボタン。拡張機能のポップアップ設定から**好きなURL（GitHubやNotion、勉強用サイトなど）に自由に変更可能**です！
2. **🏠 YouTubeトップ**:
   通常のYouTubeホーム画面へ戻ります。
3. **🎬 Watchビューでじっくり見る**:
   現在の動画を通常のYouTube動画プレーヤー（`/watch?v=...`）で再生します。
4. **🔄 もう一度この動画を見る (リプレイ)**:
   現在の動画を最初から再生し直します。

### 3. 🎬 画面右上に通常プレーヤー(Watch)遷移ボタン ＆ Watch画面での完全不干渉
- **Shorts画面の右上に「🎬 通常プレーヤー(Watch)で見る ↗」ボタンを表示**:
  クリックすると、現在の再生秒数を引き継いだまま通常のYouTube動画プレーヤー（`/watch?v=...`）にスムーズに移動できます。
- **Watchビューでは一切何もしない**:
  通常のYouTube動画画面では、拡張機能はいかなるスタイル変更やスクロール制御も行いません（100%ネイティブな動作を保証）。

### 4. 🚫 下に行くボタン（Next動画ボタン）の完全消滅
- 画面右下やリール周辺に表示される「次の動画」ボタン（`#navigation-button-down` や 下矢印アイコン）をCSSレベルで安全・完全に消滅させます（スクロール禁止ON時）。

### 5. 🗑️ 下の項目（次の動画）の不可視化
- 現在再生中の動画より下にある後続のリール要素のみを安全に不可視化。動画自体の再生やレイアウトを壊さず、次の動画のチラ見えや先読みを遮断します。

### 6. 🛑 1本見たら自動停止（ループ殺しモード）
- Shorts特有の「同じ動画を無意識に何周もループして見てしまう現象」を防止。
- 動画が終了すると自動で一時停止し、上記の脱出ポップアップを表示します。

### 7. 🚷 YouTube全体からShortsを消滅（フィード抹殺モード）
- YouTubeトップページのShorts棚、左サイドバーの「Shorts」メニュー、検索結果内のShorts一覧を非表示にします。

### 8. 🔄 常時通常プレーヤー転送 (/watchへ強制リダイレクト)
- `/shorts/{id}` へのアクセスを検知した瞬間、自動的に `/watch?v={id}` にリダイレクト！

### 9. ⏰ ドパガキ警告タイマー
- Shorts視聴時間が指定時間（1分 / 3分 / 5分 / 10分）を超えると、画面全体に警告＆脱出ポップアップが出現。

### 10. 📊 ドパミン防衛統計ダッシュボード
- 無意識にスクロールしようとして阻止された回数をリアルタイムにカウント！

---

## 📦 インストール＆アップデート方法

### アップデート手順（最新の修正を反映する場合）
1. Chromeで `chrome://extensions/` を開きます。
2. 「**NoScroll Shorts - 最強ドパガキ対策**」カードの右下にある **🔄（更新ボタン）** をクリックします。
3. YouTubeのタブを開き、ページを再読み込み（`F5`）してください。
